Experiment 5: My Workspace Dashboard
Aim
To build a clean dashboard interface in Flutter using layout widgets to organize information and quick-access options.
Description
The app is titled My Workspace and presents a student workspace dashboard.

The screenshots show:
- A welcome section with Hi, Student! and the subtitle Here's what's happening today.
- A Student Profile banner with the subtitle Mobile App Development.
- A Quick Access section with tiles such as Notes and Calendar.
- Additional dashboard tiles including Messages and Settings.
- An information banner advising the use of Row, Column, Container, GridView and Expanded to build clean, responsive dashboards.

Widgets Demonstrated
Based on the dashboard's on-screen guidance, the layout demonstrates the use of:
- Row
- Column
- Container
- GridView
- Expanded
The interface also uses text, icons, cards/tiles, spacing, rounded corners, and shadows to organize the dashboard.
How to Run
1. Ensure Flutter is installed and configured.
2. Open the Flutter project directory in a terminal.
3. Connect an Android device or start an emulator.
4. Run:
   flutter pub get
   flutter run
Expected Result
The app should display the My Workspace dashboard with a welcome section, student profile banner, quick-access tiles, and a layout information banner.
Conclusion
This experiment demonstrates how Flutter layout widgets can be combined to create a structured and responsive dashboard interface.
